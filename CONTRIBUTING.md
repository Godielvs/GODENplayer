# Contributing
Build and run deterministic tests before proposing changes. Preserve real-time audio bounds, event-driven idle behavior, existing presets, profile migrations and rollback. Do not lower refresh/quality to hide regressions. Use one compiler worker unless explicitly arranged otherwise.

Describe the concrete behavior and validation, including failures and untested hardware. Keep source and shader consumer from the same build. A successful compile is not visual approval. Add focused tests for material contracts, not tests that merely repeat implementation.

Never submit music, personal profiles, caches, diagnostics with private paths, credentials or private captures. Third-party code/resources require a source and specific license; root MIT does not cover them. Pending shader rights must be resolved before representing the project as freely redistributable. No automatic deployment/publication or production secrets belong in CI.
