GODENplayer — Beta

GODENplayer is an independent foobar2000 configuration and set of native
components. It is not affiliated with or endorsed by the foobar2000 authors.
This package contains the complete unmodified official foobar2000 2.25.10 x64
installer and freshly built GODENplayer, Columns UI and Spectrum components.
Playback Statistics 3.1.11 is an optional download from the official site;
its DLL is not bundled. Installation can finish without internet.

Original project code is MIT. Third-party code, shaders, fonts and icons have
separate terms and are excluded from that MIT grant. Some effects have unresolved
redistribution rights, and the icon's similarity/rights question remains open.
The project is not wholly MIT or fully
cleared for public distribution. Read LICENSE-SCOPE.md, SHADER-PROVENANCE.md
and ICON-PROVENANCE.md and all installed notices before redistributing.

Discord cover sharing is optional and requires permission for the selected
services. New setup offers Automatic with Uguu, Catbox and catalogue lookup;
personal-key ImgBB and custom relays are also available. Upload services receive
only a metadata-free PNG thumbnail (at most 512 x 512 and 1 MiB), not music files
or local paths. Uploaded images are public: Uguu links expire, while Catbox and
ImgBB images may persist. Catalogue lookup sends artist/album queries without
uploading the local image. Catalogue and public-upload covers are delivered
through wsrv.nl, a shared external image proxy.
Disabling sharing stops new uploads and does not delete prior images.

Presence text/progress works without covers. Existing provider and permission
choices are preserved; a private relay never silently switches to a public
upload service. Custom relay credentials are protected locally using Windows DPAPI.

The public payload contains no personal library or profile. Upgrades copy the
existing installation and profile locally to preserve preferences, playlists,
ratings, history and caches, and retain a rollback. Profile data is not uploaded
by the installer. The complete corresponding-source ZIP accompanies this installer;
its manifest identifies effective source files, patches, dependencies and hashes.
