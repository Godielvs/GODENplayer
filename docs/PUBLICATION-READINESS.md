# Publication readiness

The first public beta is available in
[GitHub Releases](https://github.com/Godielvs/GODENplayer/releases/tag/v5.1.0-beta.18-public.12).
The preparation and qualification records below describe its build-time evidence.
Read the exact delivery's `QUALIFICATION.md` and `SHA256SUMS.txt` before using its installer.

## Completed preparation

- Explicit QA media inputs without personal defaults; retained integration tools
  documented in `QA-TOOLS.md`. Offline negative tests cover privacy, mixed
  candidates, ambiguous Windows archive paths and corrupt copies/exports.
- Checked-in transactional delivery finalization with sanitized evidence and
  byte/hash correspondence. Failed/unbound measurements remain failed/unbound;
  benchmark fixtures do not claim new application performance evidence.
- Separate source export, without laboratory Git history or personal profiles.
- Own-code MIT scope, pinned dependencies, corresponding modified dependency
  sources, license texts, credits and explicit unresolved permission records.
- Intact official foobar2000 installer and host; optional official Statistics
  download rather than an embedded third-party component.
- Public Catbox/private relay/off policy, first-upload disclosure, protected
  private credentials and no personal endpoint in public defaults.
- Hand-authored pixel wordmark provenance: the historical Homemade Robot
  outlines are no longer shipped, so their old notice has been removed.
- Bounded cover verification state and correct WIC/COM teardown, with production
  method lifecycle tests and real PNG encoding against a fake network.
- Origin plus delivery PNG validation, persistent bounded encoding progress and
  damaged-storage recovery. Generated live images were decoded at both endpoints;
  a human confirmed a new cover in Discord after restart on the preceding native
  candidate with the same cover implementation. This does not guarantee service
  availability or comprehensive reconnection/network behavior.
- Real Inno download-procedure tests for good, invalid, altered, oversized,
  interrupted, unavailable and offline responses.
- Explicit native toolchain selection, one native worker, and separate CI
  correctness modes instead of treating shared-runner timing as qualification.
- Read-only CI workflow without publication or production credentials.
- A separate [compatibility matrix](COMPATIBILITY.md), official portable-mode
  installation, unrelated-foobar state checks, bundled-runtime import closure,
  proxy recovery, GPU unsupported-adapter dormancy and constrained-window probes.
- Owner-authorized B / Angular deployment to all three existing Discord static
  asset keys and the separate general application icon, with saved/reloaded
  portal state and decoded CDN checks. The static assets match the approved
  source bytes; the general icon is a portal-normalized 256 px rendition.

These statements describe prepared mechanisms and bounded test evidence.
They do not replace the exact candidate build and installer transaction results.

## Beta publication scope

The public.12 release includes synchronized source documentation, a clean
source export, corresponding dependency sources, an installer and bound hashes.
Its generated delivery report identifies exact file transactions and any
first-boot, active-upgrade, rollback or visual observations. Historical reports
stay attached to their original candidates. The Kerr runtime supplement retains
observed stalls and does not claim an unconditional performance pass.

Public.12 adds the Album palette-cache correction and the reviewed README media.
The recorded footage used the preceding public.11 identity with that same
correction; its capture receipt remains attached to those exact bytes. Current
packaging results belong to public.12's generated delivery report, not to the
earlier demo or the frozen public.11 installer.

The broader matrix below is required before claiming comprehensive platform
qualification. A beta may document untested physical monitors, target OS variants,
hosted CI and extended network cases as limitations. Source upload alone does
not establish these results. Publication, repository creation and release upload
are separate from build qualification; the attached build reports remain unchanged.

## Outstanding work before claiming a fully qualified public release

1. Resolve the shader redistribution grants and Kerr-Newman's remaining
   contribution permissions recorded in [shader provenance](SHADER-PROVENANCE.md).
   Its GPL-covered renderer is now an independent native program with sources.
   Credits,
   substantial modifications and the presence of a license text do not grant
   missing permissions or establish compatibility of the integrated binary.
2. Observe the complete player: Library/Album, audio/resume/seek, GlyphFlow,
   large artwork/indexing, cadence and matched performance. Headless fixtures
   do not establish these visual and interaction results.
3. Observe PMv2 across physical monitors/scales, menus, dialogs and click
   coordinates. Static geometry and a single-DPI probe are narrower evidence.
4. Extend complete-player Presence reconnection, long-track and varied-network
   coverage beyond the generated-cover, restart and real Discord observations.
5. Run the workflow on a fresh hosted runner, then inspect its result. Local
   builds and prerequisite checks cannot establish a hosted CI pass.
6. Bind first boot, active-player upgrade and rollback observations to the exact
   final installer. The frozen public.7 delivery passed these bounded runtime
   checks on its own installer; they cannot be substituted for a later setup.
   Consult the matching delivery transaction fields for reruns. Filesystem
   faults do not simulate arbitrary
   power loss. Complete production mutation-message coverage remains broader
   than any listed disposable rejection observations; a compile gate alone is
   static evidence. The exact delivery report identifies the boundaries tested.
7. Run representative clean Windows/Windows N environments and physical display
   configurations. ARM emulation, Wine, HDR, OS accessibility integration and
   arbitrary antivirus products are not established by local fixtures.
