# Header wordmark

The GODENplayer wordmark uses original pixel-art geometry covered by the
project's MIT license. It requires no external font or font outlines.

The standard and compact matrices in `assets/pixel-ui/source/pixels.json`
produce the SVGs under `assets/pixel-ui/brand/` and the compiled glyphs in
`src/component/pixel_ui/goden_pixel_assets.generated.hpp`.
`PanelD2D::godenWordmark` renders those pixel paths.

The application icon and third-party shaders have separate terms; see
[license scope](../LICENSE-SCOPE.md).
